29 тестов ядра, отдельная storage-интеграция без ошибок, чистые сборки C3/S3. Реальная рыбалка, ток/автономность и аппаратный runtime не проверялись. Старый пакет совместим с хабом; новый протокол и переработка хаба остаются следующим этапом.
