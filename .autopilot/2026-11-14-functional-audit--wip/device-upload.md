# Первый фактический upload на тестовую плату

2026-11-15. Пользователь разрешил запись, затем отдельно указал не делать бэкапы и подтвердил C3 после промежуточной ошибки S3. Инструментальный chip-id: ESP32-C3, flash4MB. Единственный выбранный USB serial порт проверен; уникальные идентификаторы в публичный отчёт не включаются.

Проверенный sensor-выпуск загружен штатным PIO target upload для xiao_esp32c3. Результат: SUCCESS, hash записанных данных verified, hard reset выполнен. Первая попытка во время ошибочного уточнения модели была остановлена на компиляции до flash.

Короткое чтение Serial после загрузки получило0байт: стартовый вывод мог быть пропущен. Это не подтверждает и не опровергает готовность IMU. Для аппаратной диагностики следующий выпуск добавляет явный USB status-запрос. MAC/полный flash dump не публикуются; ненужный агентский backup удалён по уточнению пользователя.
